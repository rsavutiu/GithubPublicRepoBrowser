Privacy Policy

GitHub Trending Explorer — Last updated: March 27, 2026

TL;DR

This app does not collect, store, or share any personal data. It connects only to GitHub's public APIs and our own static cache. No analytics, no trackers, no ads.

1. Information We Collect

We do not collect any personal information. The app does not use analytics services, crash reporting SDKs, advertising frameworks, or any third-party tracking.

2. GitHub Authentication (Optional)

If you choose to sign in with GitHub to star repositories, the app uses GitHub's standard OAuth flow. During this process:

  • Your GitHub access token is stored locally on your device only (in encrypted shared preferences).
  • The token is used solely to authenticate API requests to GitHub on your behalf.
  • We never transmit your token to any server other than api.github.com.
  • You can log out at any time, which deletes the token from your device.

3. Data Stored on Your Device

The app stores the following data locally on your device:

  • Saved searches — your bookmarked search configurations (query text and filter selections).
  • Favorite repositories — repos you bookmark for quick access.
  • GitHub OAuth token — only if you sign in (see above).

All local data can be cleared by clearing the app's data in your device settings or by uninstalling the app.

4. Network Requests

The app makes network requests to:

  • GitHub API (api.github.com) — to search repositories, fetch READMEs, commit history, contributors, and dependencies.
  • GitHub Pages cache (rsavutiu.github.io) — to load pre-cached trending repository data. This is a static JSON file host with no server-side processing.
  • GitHub avatar CDN (avatars.githubusercontent.com) — to display user and organization profile images.

No data is sent to any other servers.

5. Third-Party Services

The app does not integrate any third-party analytics, advertising, or data collection services. The only external service used is the GitHub API, governed by GitHub's Privacy Statement.

6. Children's Privacy

The app does not knowingly collect any information from children under 13. Since we collect no personal data from any user, no special provisions are needed.

7. Changes to This Policy

If we update this privacy policy, the changes will be posted on this page with an updated date. Since the app collects no data, significant changes are unlikely.

8. Contact

If you have questions about this privacy policy, you can open an issue on the GitHub repository.
